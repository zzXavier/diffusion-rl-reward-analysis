# Source register

[DDPO-PyTorch](https://github.com/kvablack/ddpo-pytorch/tree/1958463f020112c9a7bc85768d296daacc2e1b4b), MIT. `src/ddpo/ddim_with_logprob.py` comes from its `ddpo_pytorch/diffusers_patch` directory. The original license is retained alongside it. The sole compatibility edit imports `randn_tensor` from `diffusers.utils.torch_utils`. That upstream file credits the original Hugging Face Diffusers DDIM implementation. The runner, prompt split, per-trajectory logging and independent color evaluator are local additions.

Formal base [SD1.5](https://huggingface.co/stable-diffusion-v1-5/stable-diffusion-v1-5/tree/451f4fe16113bff5a5d2269ed5ad43b0592e9a14), smoke base [tiny SD](https://huggingface.co/hf-internal-testing/tiny-stable-diffusion-pipe/tree/3ee6c9f225f088ad5d35b624b6514b091e6a4849). Model weights are loaded from the local cache. P02's frozen scoring routine and preference-head feature order are reproduced in `src/pickscore.py`; the formal run records the SHA-256 of the supplied head. P02 uses the fixed [PickScore checkpoint](https://huggingface.co/yuvalkirstain/PickScore_v1/tree/a4e4367c6dfa7288a00c550414478f865b875800).
